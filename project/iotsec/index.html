IoTSec: Scalable, Real-time Malware Detection for Smart Environments

Jul 15, 2022

IoTSec, Edge Network Malware Detection with Deep Learning for Smart Home, was funded by a Google Cloud Research Award (2022-2023).

ADAL’s work in this area includes:

  • MalIoT, a scalable, end-to-end network traffic analysis system that detects IoT malware traffic in real time. It uses Apache Kafka and Apache Spark to scale with the number of IoT devices and Intel’s oneAPI software stack to accelerate model inference.
  • MalBuster, a scalable and real-time malware detection system for IoT devices in smart homes, communities and cities. It compares a suite of machine learning and deep learning models and uses a drift adaptation algorithm to keep pace with a changing malware landscape.

Team

  • Ethan Weitkamp, Yusuke Satani and Adam Omundsen, student researchers
  • Dr. Jingwen Wang and Dr. Peilong Li, Elizabethtown College
